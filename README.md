## Sobre o Projeto

Muitas pessoas interessadas em ingressar na área de tecnologia se sentem perdidas com a vasta quantidade de opções de carreira disponíveis. O **Chatbot de Carreira** visa solucionar esse problema atuando como um mentor virtual, ajudando usuários a descobrir a melhor carreira em tecnologia através de uma entrevista personalizada e interativa.

### Funcionalidades Principais

* **Entrevista Guiada:** Conduz uma conversa fluida para coletar informações sobre o usuário.
* **Análise de Perfil:** Utiliza IA para processar as respostas.
* **Recomendação de Carreira:** Sugere carreiras em tecnologia personalizadas.

## Como Executar o Projeto Localmente

Para rodar este projeto em seu ambiente de desenvolvimento local, siga os passos abaixo.

### Pré-requisitos

* [Node.js](https://nodejs.org/en)

### Passos de Instalação

1.  **Clone o repositório:**
    ```sh
    git clone https://github.com/MaduAraujo/Chatbot-de-Carreira.git
    ```

2.  **Navegue até o diretório do projeto:**
    ```sh
    cd Chatbot-de-Carreira
    ```

3.  **Instale as dependências:**
    ```sh
    npm install
    ```

4.  **Execute o servidor de desenvolvimento:**
    ```sh
    npm run dev
    ```

5.  **Abra no navegador:**
    O projeto estará disponível em `http://localhost:5173` (ou outra porta indicada no terminal).
